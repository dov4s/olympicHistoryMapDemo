# Россия и мир Олимпийских игр

Интерактивная карта по истории Олимпийских игр, разработанная для ГИВЦ Минкультуры. Сайт доступен по [ссылке](https://dov4s.github.io/olympicHistoryMapDemo/).

Победитель конкурса "Твой проект" от ВШЭ.
